\# Employee Leave Management System



\## Overview



A full-stack Employee Leave Management System built using ASP.NET Core 10 Web API, React, MySQL, Docker, GitHub Actions, and Azure DevOps CI/CD pipelines.



\---



\## Features



\- Employee Login

\- JWT Authentication

\- Apply Leave

\- View Leave History

\- Dashboard

\- Role-Based Access

\- Docker Containerization

\- CI/CD Pipeline



\---



\## Tech Stack



\### Backend

\- ASP.NET Core 10 Web API

\- C#

\- Dapper

\- JWT Authentication



\### Frontend

\- React

\- Vite

\- JavaScript



\### Database

\- MySQL



\### DevOps

\- Docker

\- Docker Compose

\- GitHub Actions

\- Azure DevOps YAML Pipeline
